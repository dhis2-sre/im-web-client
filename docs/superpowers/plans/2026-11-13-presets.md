# Presets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the web client onto im-manager's `/presets` resource and ship the agreed preset flows: manage presets, start one or several instances from one, keep a tweak, save an instance as a preset.

**Architecture:** Pure request builders and helpers (unit-tested) sit under `src/views/presets/` and `src/views/instances/dhis2-v2/`. `useStackDeploymentCreation` gains the preset calls. `Dhis2V2Form` grows explicit modes so one form serves new instance, instance edit, and the preset page. The prototype in the main checkout (uncommitted, `prototype/presets-ux`) is a behaviour and copy reference only.

**Tech Stack:** React 18, TypeScript, react-final-form, @dhis2/ui, axios-hooks (`useAuthAxios`), Jest (ts-jest, node env, co-located `*.test.ts`), Vite. Mock backend: `~/Documents/github/im-mock-api` (plain Node).

**Spec:** `docs/superpowers/specs/2026-11-13-presets-design.md`

## Review Focus

1. A preset with pgAdmin on, copied by the browser (Duplicate, from an instance, "Save as a new preset", Create several): the pgAdmin login must be asked for, not left blank to fail with a 400. Pinned by `uncopyableParameters` tests (Task 2) and the lossy-validation test (Task 2, `missingUncopyable`).
2. Editing a preset without touching its sensitive fields must not overwrite them with blanks or `***`. Pinned by `buildEditPresetRequest` tests (Task 2).
3. Starting from a preset and only changing group, description, name or lifetime must not offer "Update preset" or move the shared preset. Pinned by `changedFromPreset` tests (Task 2).
4. Renaming a preset to a name already used in the target group must be refused before save, while keeping its own name in its own group must pass. Pinned by `allowOwnName` tests (Task 2).
5. Creating from an unchanged preset must send no instance overrides, so the server's stored values (including secrets) are used as is. Pinned by `buildFromPresetRequest` tests (Task 2).
